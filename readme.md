## Cutter Challenge

Application for timer and scoring management of the Cutter Challenge.

## Installation

- Download Setup exe from the [Releases](https://github.com/IgnisAlienus/Cutter-Challenge/releases)

## Keybindings for Stopping Timers

- `1` (not NUMPAD1) - Stop Timer 1
- `2` (not NUMPAD2) - Stop Timer 2
- `3` (not NUMPAD3) - Stop Timer 3

## Production Leaderboard Overlay

**Show Leaderboard on TV** switches the local TV window and publishes the same standings snapshot to the Cloudflare overlay. Cloudflare setup and local configuration are documented in `cloudflare/leaderboard-overlay/README.md`.
